# Job Processor (Go)

Сервис обработки фоновых задач с использованием goroutines и worker pool.

## 📌 Описание

Проект реализует систему обработки задач в фоне с поддержкой:

* очереди задач
* параллельной обработки
* retry-механизма при ошибках

Подходит для задач вроде:

* отправки email
* обработки событий
* фоновых вычислений
* логирования и аналитики

---

## 🏗 Архитектура

Система состоит из нескольких ключевых компонентов:

### 1. Очередь задач (Queue)

Буферизированный канал, в который поступают задачи:

```go
jobs chan Job
```

* принимает задачи от внешних источников
* распределяет их между воркерами

---

### 2. Worker Pool

Набор горутин (воркеров), которые параллельно обрабатывают задачи:

```text
           +-------------+
           |   Queue     |
           +------+------+ 
                  |
     +------------+------------+
     |            |            |
  Worker 1     Worker 2     Worker N
```

Каждый worker:

* читает задачу из очереди
* выполняет её
* обрабатывает ошибки

---

### 3. Retry механизм

Если задача завершилась с ошибкой:

* она повторно ставится в очередь
* количество попыток ограничено

```go
if err != nil && job.Retries < maxRetries {
    job.Retries++
    queue <- job
}
```

---

### 4. Job (задача)

Абстракция задачи:

```go
type Job struct {
    ID      string
    Payload interface{}
    Retries int
}
```

Можно адаптировать под любые типы задач.

---

## 🔄 Поток выполнения

```text
Producer → Queue → Worker → Execute
                       ↓
                    Error?
                      ↓
                    Retry
```
